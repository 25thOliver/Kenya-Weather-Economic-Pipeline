# Kenya Economic & Weather Intelligence Pipeline

A Dockerized data engineering pipeline for collecting, processing, storing, and analyzing economic and weather data for Kenya.

## Project Status

Phase 1

## Planned Data Sources

- World Bank API
- Open-Meteo API

## Planned Tech Stack

- Python
- Docker
- Apache Airflow
- MinIO
- dbt
- PostgreSQL
- Apache Superset

## Project Architecture

The final pipeline will ingest data from public APIs, store raw data in a data lake, transform the data into analytical datasets, load the results into PostgreSQL, and expose the data through analytics dashboards.

## Development

The project is developed incrementally using Docker and Git.
